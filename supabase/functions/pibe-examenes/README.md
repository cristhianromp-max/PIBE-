El proyecto de El Pibe ya tiene esta función desplegada. En una instalación distinta sustituye el marcador por el SHA-256 de una nueva autorización criptográfica generada para el propietario, configura la carpeta y actualiza las constantes en Codigo.gs. El valor original solo se guarda en el documento privado. La función verifica la autorización del propietario para vincular el puente y la asociación con la visita al subir o leer. Para las operaciones públicas la configuración de esta función usa verify_jwt=false. Las claves de administración permanecen en el servidor.
